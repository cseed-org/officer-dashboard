# Support

| Need | Where to go |
| --- | --- |
| Setup, usage or contribution question | [GitHub Discussions](https://github.com/cseed-org/officer-dashboard/discussions); include the area, what you tried and relevant versions. |
| Reproducible bug | [Bug report form](https://github.com/cseed-org/officer-dashboard/issues/new?template=bug_report.yml); include steps and expected/actual behavior. |
| Feature idea | [Feature request form](https://github.com/cseed-org/officer-dashboard/issues/new?template=feature_request.yml); describe the problem and who benefits. |
| Missing or incorrect documentation | [Docs issue form](https://github.com/cseed-org/officer-dashboard/issues/new?template=docs_issue.yml); link the page and suggest a correction. |
| Suspected vulnerability | Follow [SECURITY.md](SECURITY.md) for private reporting. Do not post security details in public issues or Discussions. |
| Community conduct concern | See the reporting section in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |

Search existing issues and discussions first. Remove tokens, cookies, personal information and private club data from logs and screenshots. Community support has no guaranteed response time.
